# HopeConnect 🤝

HopeConnect is a frontend website created for an NGO to provide information about the organization and support donation activities.

## 🌐 Live Website

[https://hope-connect-eight.vercel.app/](https://hope-connect-yi1z-mawc58j98-thorat.vercel.app/)

## ✨ Features

- Clean and simple user interface
- NGO information
- Donation support section
- Responsive website design
- Easy navigation

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- React
- Vite
